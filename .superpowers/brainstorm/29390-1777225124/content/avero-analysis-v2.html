Avero Strengths

  • Approve/Reject pending approvals inline — eliminates context switch to Approvals page entirely
  • Recent history persists in localStorage and deduplicates — matches Linear's behavior exactly

Next Priority Fix

Add fuzzy search (score each result by Levenshtein distance to query, sort descending). Linear uses this to surface "DB" when you type "database". A simple 15-line implementation would close the last meaningful gap against Linear's palette.
