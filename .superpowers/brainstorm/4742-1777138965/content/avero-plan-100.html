P0
Connect WebSocket to Dashboard — eliminate 15s polling lag
The WebSocket server at /api/companies/{companyId}/events/ws is fully built and emitting events. The Dashboard and ActiveAgentsPanel use 15-second polling instead. Create a useCompanyLiveEvents(companyId) hook that: (1) opens a WebSocket connection, (2) dispatches events to React Query cache invalidations, (3) reconnects on drop (exponential backoff). Replace refetchInterval: 15000 with this hook in Dashboard.tsx and ActiveAgentsPanel.tsx. Result: agent status changes appear in <1s instead of up to 15s. Zero backend work — the server already sends events.
