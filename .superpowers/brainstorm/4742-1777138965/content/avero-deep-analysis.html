1. Onboarding Wizard

A 4-step modal wizard (Company → Agent → Task → Launch) that walks new users from zero to a live running AI agent. Combines brand left-panel, vertical step progress stepper, adapter selection, live environment tests, and a launch confirmation summary.

Avero Strengths

  • The brand left-panel with logo, vertical numbered stepper, and tagline creates immediate product identity that no competitor replicates during onboarding. The split-screen layout communicates enterprise credibility before a user types a single character.
  • Live adapter environment test on Step 2 is unique — users get a real-time probe result (pass/warn/fail with actionable debug hints) before committing. No competitor validates configuration inline during setup.
  • Cmd/Ctrl+Enter keyboard shortcut for "next step" is surfaced with a visible platform-aware hint — a small signal that communicates keyboard-first product philosophy from first contact.
  • The Agent Preview card on Step 2 updates live as the user types, providing immediate feedback. The "Ready to deploy" status badge is a strong confidence signal with zero additional clicks.

Avero Gaps

  • No progress indicator showing estimated completion time or decision count remaining per step. Linear's onboarding sets upfront expectations ("takes about 2 minutes") which reduces abandonment.
  • The "More Agent Adapter Types" toggle hides options behind an extra click. If a user's preferred adapter (e.g., Cursor, OpenCode) is not in the primary grid, they may not discover it and will churn.
  • Step 3 pre-fills a specific hiring-focused task description which confuses users not building a startup simulation. No template selector or quick-clear reduces first-run cognitive load.
  • No import or template path. Asana and Notion both offer pre-built starting templates. Avero requires fully manual configuration on every new company, raising cold-start friction.
Priority Fix

Add 3–4 one-click starter templates on Step 3 (e.g., "Research competitor pricing", "Write a hiring plan", "Build an API spec") so new users skip blank-slate anxiety and reach a live run faster — this directly raises first-run completion rate, the most important onboarding metric.

The primary landing page after login. Shows 4 metric cards (agents enabled, tasks in progress, month spend, pending approvals), 4 chart cards (run activity, priority, status, success rate), an Active Agents panel with live run cards, real-time activity feed, and recent tasks list.

Avero Strengths

  • WebSocket-driven live data with animated activity row entry (fade + slide-from-bottom) is genuinely real-time. The "Live" indicator on the agents panel header with pulsing cyan dot is a premium signal no competitor matches at the dashboard level.
  • Budget incident banner (red gradient with paused agent count, project count, and pending approvals in one line) surfaces critical operational state without navigating away — a CFO-grade signal.
  • The 4-chart grid (Run Activity, Priority, Status, Success Rate) gives a complete operational picture on a single screen. Most competitors show only one or two charts at this navigation level.
  • Plugin slot support via PluginSlotOutlet means the dashboard is extensible — teams can embed custom widgets without forking the codebase. This is an enterprise differentiator.

Avero Gaps

  • No drag-to-reorder or widget customization on the 4 metric cards. Linear and Notion let users pin and reorder dashboard widgets. A CTO who wants costs front-and-center cannot surface them above agent count.
  • The activity feed uses plain bordered list items with no visual differentiation between agent actions, human actions, and system events. Linear's feed uses color-coded avatars and action type icons that make scanning much faster.
  • No date-range selector on the 4 charts — locked to "Last 14 days" with no ability to change the window. Copilot Studio and Gemini Enterprise both allow time-range selection.
  • The dashboard breadcrumb shows only "Dashboard" with no company name, role indicator, or last-updated timestamp. After switching companies repeatedly this creates disorientation.
Priority Fix

Add a time-range selector (7d / 14d / 30d / custom) to the 4 chart cards — this single change converts the dashboard from a snapshot into a trend-analysis tool and directly closes the largest analytical gap against Copilot Studio and Gemini Enterprise.

Avero Strengths

  • Live run count badge on the Dashboard nav item gives users a real-time "agents running now" signal without opening any page — uniquely useful in an AI ops context that static project management tools cannot offer.
  • Collapse-to-icon-rail with smooth 200ms transition and hover tooltips is well-implemented. The DensityToggle (Compact/Default/Comfortable) gives users fine-grained control that Linear only added in 2025.
  • Plugin slot support in the sidebar means enterprise customers can embed custom nav items without forking — a strong extensibility story for OEM and reseller deployments.
  • Inbox badge with dual-tone alert state (danger tone for failed runs, default for normal unread) is a useful severity signal that task-management competitors completely lack.

Avero Gaps

  • The Work section contains 17 nav items simultaneously with no pinning or per-item collapse. This is the single biggest daily friction point in the entire product. Linear solves this with Favorites pinning and per-section collapsibility.
  • No drag-to-reorder sections or nav items. Users who live in Approvals cannot move it above Issues. Linear's sidebar is fully drag-rearrangeable per workspace.
  • No hover-intent quick-create (+) buttons per section. Users must navigate to a page before finding the New button. Linear shows an inline + on hover next to each section header for instant creation.
  • Active state differentiation is subtle — only a light background tint. Linear uses a left-accent border on the active item making it scannable at a glance from across the room.
Priority Fix

Introduce section collapsibility and a Favorites pinning system — let users collapse the 17-item Work section to their 3–5 most-used items and pin them to the top of the nav. This would raise the sidebar score from 68 to approximately 83 and close 80% of the gap versus Linear.

Avero Strengths

  • The org-chart tree view with indented hierarchy and border-left connectors is unique — no competitor shows AI agents as an organizational structure. This communicates the company-of-agents mental model that resonates with enterprise buyers.
  • The pulsing animated "Live" indicator (cyan pulse + count badge) linking directly to the active run from the agents list lets users see which agents are working without leaving the page.
  • Bulk selection with a floating bottom-bar action panel (Pause All / Delete All with window.confirm) is well-implemented and follows desktop convention for bulk operations.
  • 15-second polling gives near-real-time status without taxing the server — a practical compromise that keeps the list feeling live during active operations.

Avero Gaps

  • Agent rows show only name, role, adapter type, last heartbeat, and status. No cost-per-agent column, no task count, no success rate, no token usage. Copilot Studio and Gemini Enterprise show cost and usage inline — critical for enterprise cost governance.
  • Bulk actions only include Pause and Delete. No "Assign to project", "Change adapter", or "Export". For teams managing 50+ agents this is a daily friction point.
  • Search is client-side only and filters on name alone. No ability to search by role, adapter type, or status text. No column sorting — the list is always in default order regardless of what users want to surface first.
  • No column sorting at all. Users cannot sort by last active, by cost, or by status. A CTO reviewing 40 agents wants to sort by "highest cost this month" immediately.
Priority Fix

Add a "Cost (MTD)" column to the agents list row and enable column sorting by clicking the header — the moment a CTO can see which agent spent the most this month at a glance, the agents list becomes a daily governance tool rather than an inventory screen.

Avero Strengths

  • This panel is the clearest product differentiator in the entire Avero UI. Seeing live agent transcripts scrolling in real-time from the dashboard is something no task-management competitor offers. The animated ping dot (cyan, animate-ping) on active cards is visually unambiguous.
  • The run card design (fixed height, scrollable transcript, card-level cancel button, link to full run, elapsed timer) packs maximum operational information into a minimal footprint — a CTO can monitor 4 concurrent agents from a single glance.
  • The cyan glow border and background tint on active cards distinguishes active from finished runs without color-only cues. The visual treatment is premium and immediately communicates "this is running now."
  • Cancel button appears on hover with destructive styling (red hover state) — destructive actions require intent, not permanent visibility. This is correct interaction design.

Avero Gaps

  • Hard limit of 4 cards. When 10+ agents are running simultaneously, only 4 are visible. There is no expand/show-all inline view — the user must navigate away from the dashboard entirely to see all active runs.
  • Run cards do not show token cost or estimated cost-to-completion. Copilot Studio shows cost per session inline. For enterprise customers running expensive models, cost visibility per live run is a governance requirement.
  • No ability to send a message or inject a prompt into a running agent from the dashboard card. Gemini Enterprise allows mid-run intervention from the monitor view. Avero requires navigating to the full run detail page.
  • The transcript surface shows only 5–8 visible lines with no expand-to-fullscreen on the card itself. Users must click through to run detail to read more than a glance of the transcript.
Priority Fix

Add an inline cost badge to each active run card showing estimated cost so far (e.g., "$0.14") — this is the single most-requested enterprise feature in AI orchestration platforms and directly addresses the governance gap versus Copilot Studio and Gemini Enterprise.

Avero Strengths

  • J/K navigation with A/R keyboard shortcuts is the highest power-user feature density of any page in the product. A reviewer can process 20 approvals in under a minute without touching the mouse. No competitor offers this pattern for AI agent approvals.
  • Bulk Approve All / Reject All with pending count in the header is mission-critical for teams that generate many low-stakes approval requests. The yellow badge count on the Pending tab keeps urgency visible from the navigation rail.
  • The ring-2 focus ring on the keyboard-focused card provides unambiguous visual tracking of which item is active — good for both accessibility and keyboard-primary users simultaneously.
  • The revision_requested status is handled alongside pending in the filter logic — the system recognizes that approval review is iterative, not binary. More sophisticated than Copilot Studio's simple approve/reject model.

Avero Gaps

  • No SLA or aging indicator on approval cards. If an approval has been waiting for 4 hours while an agent is blocked, there is no visual urgency signal. Copilot Studio shows time-waiting and escalation status. An overdue card should show a red border or countdown.
  • No approval delegation or assignment. If a reviewer is unavailable, there is no way to route an approval to another team member. Enterprise deployments require routing rules and delegation chains.
  • No "request more information" workflow from the queue view — the revision_requested status exists in the data model but there is no UI in the queue for a reviewer to type a revision message without navigating to the full detail page.
  • The keyboard shortcut legend is plain muted text with no styled kbd badges. Linear-style key caps would significantly improve discoverability for users who are not already keyboard-first.
Priority Fix

Add an aging indicator to each approval card showing how long it has been waiting (e.g., "Waiting 2h 14m") with a color shift from gray to amber to red over time — this gives operations teams immediate triage intelligence and justifies the approvals queue as a real-time control plane.

Avero Strengths

  • Recent commands persistence in localStorage with deduplication and push-to-top is correctly implemented — the palette learns usage patterns and surfaces the most recently used items first without any server round-trip.
  • The palette searches across issues, agents, and projects simultaneously and surfaces Identity badges (agent avatars) next to assigned issues — unique context that competitor palettes do not show inline.
  • Live API search activates only when query.length > 0 and falls back to cached list data when the palette is open and empty — a smart query strategy that avoids unnecessary server load on palette open.
  • The KbdBadge component on the "C" shortcut for create is correctly placed within the result item — users who land on that item with keyboard navigation see the shortcut hint in the right context.

Avero Gaps

  • The palette navigates to things but cannot act on them. You can go to an agent page but you cannot Pause Agent, Start Run, or Assign Issue to Agent from the palette. Linear can perform any action on any issue without leaving the palette. This is the most critical capability gap.
  • No fuzzy matching — the palette uses exact substring matching. Typing "db mig" will not surface "database migration". Linear uses Fuse.js-style fuzzy matching that tolerates typos and word-order variation.
  • The Actions group has only 3 items (new issue, new agent, new project). For a product with 17+ nav sections, the palette should expose many more quick-create actions: new goal, new routine, start approval review, trigger a specific agent run.
  • No visual differentiation between entity types in results. Issues, agents, and projects use similarly-sized icons and text weight. Linear uses distinct visual chips per entity type making type-scanning instant.
Priority Fix

Implement agent actions directly in the palette — "Pause [Agent Name]", "Start run for [Agent Name]", "Approve pending #123" — this is the difference between a navigation launcher and a true command center, and is the single move that would push Avero's palette closest to Linear's score.

Avero is Beating Everyone On

  • Live agent run monitoring — the Active Agents Panel with real-time transcripts, elapsed timers, and pulsing status is a category-defining feature that no competitor offers at the dashboard level. Avero scores 80 here; Linear scores 15.
  • Approvals keyboard workflow — J/K plus A/R navigation is the fastest AI approval interface in the market. Copilot Studio's approval UI requires mouse clicks for every action.
  • Agent hierarchy visualization — the org-chart tree view communicates the company-of-agents mental model better than any flat list competitors use. A unique product story.
  • Onboarding live environment testing — inline adapter probe with pass/fail/warn and actionable debug commands during setup is unique and builds technical user confidence immediately.
  • Real-time data architecture — WebSocket-driven query invalidation with animated new-event entry beats the polling-only models of Linear, Notion, and Asana decisively.

Avero is Still Behind On

  • Sidebar information architecture — 17 items in the Work section without Favorites pinning or collapsibility creates daily friction that Linear solved years ago. The largest addressable UX gap in the product.
  • Command palette action depth — Avero's palette navigates to things; Linear's palette acts on things. Until agent actions are in the palette, Avero is a navigation launcher, not a command center.
  • Cost visibility per entity — no cost column on agent rows, no cost badge on live run cards, no cost per approval. Copilot Studio shows cost everywhere. A blocker for enterprise sales to CFO-aware buyers.
  • Dashboard customization — no drag-to-reorder widgets, no date-range selector on charts, no pinned metrics. Copilot Studio and Gemini Enterprise both offer this level of dashboard configuration.
  • Approval governance — no SLA/aging indicator, no delegation routing, no inline revision request workflow. Copilot Studio's approval pipeline is more operationally complete for enterprise deployments.

3 Changes That Make Avero #1 Overall

  • Add cost visibility everywhere, immediately. A "$0.14" badge on each live run card, a "Cost MTD" column on the agents list, and a budget indicator per approval. This closes the largest gap against enterprise competitors and converts Avero from "cool demo" to "boardroom-defensible platform" in a single sprint.
  • Make the command palette an action center. Add agent actions (Pause, Start Run, Assign Issue) and approval actions (Approve, Reject) directly into the palette. This is the move that separates Linear from every other issue tracker — it would separate Avero from every other AI orchestration tool.
  • Sidebar Favorites pinning and section collapsibility. Let users collapse the 17-item Work section to their 3–5 daily-use items and pin them to the top. Add hover-intent quick-create (+) buttons next to section headers. This closes 80% of the gap versus Linear's sidebar in one implementation sprint.
