# Assets

Place the following files in this directory before building:

- `icon.png` — 1024x1024 PNG, Avero logo on #18181b (zinc-900) background
- `splash.png` — 1242x2436 PNG, splash screen image (optional, app.json uses backgroundColor)
- `adaptive-icon.png` — 1024x1024 PNG for Android adaptive icon foreground

The primary brand color is #F5C518 (Avero gold) on #18181b (zinc-900) background.
